# Book Data Cleaning & Quality Validation

A Python-based data cleaning and quality validation project developed as part of the **Datheon Python for Data Engineering & Automation Internship**.

## Overview

This project demonstrates a reproducible data cleaning workflow using Pandas. It takes the book dataset generated by Task 01, introduces controlled data quality problems for testing, and produces a cleaned dataset with a JSON quality report.

The original Task 01 dataset remains unchanged.

## Features

- CSV data import and inspection
- Detection and removal of duplicate product records
- Missing price imputation using the median
- Missing rating replacement with `Unknown`
- Text normalization through whitespace removal
- Data quality reporting in JSON
- Automated dataset validation using Pytest

## Technologies Used

- Python 3.10
- Pandas
- NumPy
- Pytest
- Conda

## Getting Started

Clone the repository and navigate to the project:

```bash
git clone https://github.com/naimNB/Python-Data-Engineering-Lab.git
cd Python-Data-Engineering-Lab/02-Data-Cleaning
```

Create the Conda environment:

```bash
conda env create -f environment.yml
conda activate data-cleaning
```

## Usage

Run the steps in order:

```bash
python src/data_cleaner.py
python src/generate_messy_data.py
python src/clean_data.py
python src/quality_report.py
```

Run automated tests:

```bash
python -m pytest tests/ -v
```

## Data Cleaning Strategy

The demonstration dataset contains deliberately introduced missing values, duplicate records, and inconsistent whitespace.

Cleaning includes:

1. Trimming whitespace from text fields.
2. Deduplicating by product URL.
3. Filling missing prices using the dataset median.
4. Replacing missing ratings with `Unknown`.
5. Exporting the cleaned dataset to CSV.

**Important:** Median-imputed prices are illustrative values, not verified product prices. They should not be presented as actual prices in a production catalogue.

## Outputs

- `data/messy_books.csv` — Dataset with simulated quality issues
- `data/cleaned_books.csv` — Cleaned dataset
- `reports/quality_report.json` — Before-and-after data quality statistics

## Testing

Seven automated tests check the output dataset's schema, record count, missing values, duplicate URLs, numeric prices, report consistency, and file existence.
